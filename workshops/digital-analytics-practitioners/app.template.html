Things to do

The list state lives in the URL. Add, complete, edit, filter, delete, and share tasks while the Activity panel shows the event payload.

    Connection

    Use a browser project API key. The app disables automatic tracking so the Activity panel only contains the events in this exercise.

    The project API key is intended for client-side use. It stays in this browser tab and is kept out of the URL, so a share link never carries it. Don't enter a secret key, email address, task contents, or other private data.

    Workshop profile

    Instrumentation plan

    Untick an action you decided not to track, and edit an event name to match your plan. Property names stay fixed in this app so the room can compare payloads.

    Task text is never sent to Amplitude. Length and age support the exercise questions without collecting what somebody typed.
